# Support

Use [GitHub Issues](https://github.com/tverma101/TabletBridge/issues) for
reproducible bugs and feature requests. Include macOS/Android versions, device
model, connection mode, fork version, and safe reproduction steps.

Never post pairing tokens, private logs, personal data, or screenshots
containing confidential content. Security reports belong in the private
process in [SECURITY.md](SECURITY.md).

This fork is independent from the upstream Side Screen project. Upstream
support channels, donations, releases, and issue trackers do not represent
Tablet Bridge.
